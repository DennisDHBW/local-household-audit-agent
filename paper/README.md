# Ausarbeitung (LaTeX)

Basis: [DHBW_Projektarbeiten_Template](https://github.com/Evolinox/DHBW_Projektarbeiten_Template) (MIT-Lizenz, siehe `LICENSE`).

- Angaben fürs Titelblatt: `settings/document.tex` (Stellen mit `TODO`)
- Kapitel: `content/chapter/NN-name/main.tex`
- Aktiv sind nur Titelblatt, Inhaltsverzeichnis und Kapitel; die übrigen Teile sind in `main.tex` auskommentiert.
- Bauen: `latexmk -pdf main.tex`
- Schreibregeln: `../docs/writing-guide.md`
